BookScan Live

Scan or type an ISBN → live lookup via Open Library + Google Books APIs
Barcode scanners type the ISBN and send Enter — works automatically here.
Data sources
Book metadata & coversOpen Library API (live)
Retail / list priceGoogle Books API (live)

Both APIs are free, keyless, and queried live from your browser — no backend or account needed. Used-marketplace offers (Amazon PA-API, eBay, BookScouter) require approved API keys, so this build estimates used value from real retail price and category, and has a clearly marked hook (fetchMarketOffers() in the source) where a real pricing API can be plugged in. Note: the canvas preview sandbox blocks live network calls — download this file and open it in your browser for real lookups.
