Book scanner with attached search for market price.
What it does:
Scan/enter an ISBN — type it or use a real barcode scanner (it fires on Enter, which is how scanners work). A "sample" dropdown lets you try any of the built-in books.
Instant market prices — offers from Amazon, AbeBooks, eBay, and BookScouter (buyback), with the best resale price highlighted.
Profit check — enter your cost and it tells you whether the book is worth flipping, with the margin calculated.
9-month price trend chart so you can see if the market is rising or softening.
Scan list — build a session inventory with per-book and total estimated resale value.
One note: the canvas runs fully self-contained in the browser, so it queries a built-in book database rather than live marketplace APIs. If you want it wired to real pricing data (e.g., a live ISBN API), I can adapt it into a deployable app with a backend — just say the word.
